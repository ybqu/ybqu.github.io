Transformers常用的Normalization都有什么

发表于2025-08-31|更新于2025-08-31|LLMsTransformersNormalization
|总字数:1k|阅读时长:3分钟|浏览量:

目前流行的就两种：LayerNorm 和 RMSNorm。早期的 GLM 系列曾经用过 DeepNorm，后来在 ChatGLM2 的时候就改成 LayerNorm 或者 RMSNorm

根据 Norm 的位置可以进一步分为 Pre-LayerNorm, Post-LayerNorm, Pre-RMSNorm, Post-RMSNorm

LayerNorm

其实目前主流的 Normalization 都有个通用的公式 \[Norm(x) = \frac{x-\mu}{\sigma}\gamma + \beta\] 其中，\(\mu\) 为均值，\(\sigma\) 为归一化的分母，比如对 LayerNorm 来说他是标准差，对 WeightNorm 来说是 L2范数。\(\gamma\) 和 \(\beta\) 为可学习的参数，可以让模型根据分布 scaling 和 shifting。有的文献把 \(\gamma\) 叫做 gain, 把 \(\beta\) 叫做 bias

对于 Layer Norm 来说，可以表示为： \[LayerNorm(x) = \frac{x-\mu}{\sigma}\gamma + \beta\] 上面公式中，\(\mu\) 为均值，\(\sigma\) 为标准差 \[\mu = \frac{1}{N}\sum_{i=1}^{N}x_i\] \[\sigma = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(x_i-\mu)^2 + \epsilon}\]

Batch Norm 也可以表示成上面的样子，只不过的计算的维度不同

Layer Norm 出来以后，大家发现 Layer Norm 效果很好，同时也想方设法去改进。在论文《Understandingand Improving Layer Normalization》中，作者仔细研究了 Layer Norm 公式的各个部分

作者做了一些实验，证明了两点：

  • \(\gamma\) 和 \(\beta\) 是数据无关的参数，如果训练和测试的分布不太一样，那就会导致 overfitting。所以作者尝试去掉 γ 和 β，然后发现效果并没有变差，反而有的会更好
  1. \(\mu\) 和 \(\sigma\) 又有什么用呢？作者通过理论和实验证明了通过减去\(\mu\)，让梯度回到0附近。而除以\(\sigma\)则让梯度的方差变小。所以 Layer Norm 提升了训练的稳定性。

作者还提出了把 \(\gamma\) 和 \(\beta\) 变成了可对输入微分的函数，然后把这个方法叫 AdaNorm。效果也很好，不过这么做让计算变得复杂了。

RMSNorm

上面的 AdaNorm 尝试做了减法，但是又做了加法，RMSNorm 则在做减法上一条路走到黑

RMSNorm（Root Mean Square Layer Normalization）论文假设 LayerNorm 中的重新中心化不再是必须的（平移不变性不重要），并提出了一种新的归一化方法：均方根层归一化（RMSNorm）。RMSNorm 通过均方根（RMS）对每一层神经元的输入进行归一化，使模型具备重新缩放不变性和隐式学习率调整的能力。相比 LayerNorm，RMSNorm 计算更为简洁，大约可以节省 7% 到 64% 的运算。

\[RMSNorm(\mathrm{x}) = \frac{x}{RMS(\mathrm{x})}\gamma\] \[RMS(\mathrm{x}) = \sqrt{\frac{1}{N} \sum_{i=1}^{N} x_i^2 + \epsilon}\] 通过实验证明了这样做效果不仅没有下降，计算效率还提升了 25%

还能在优化么？

看上面的公式，似乎能优化的也不多，要么把 \(\gamma\) 去掉，要么再修改 \(\sigma\) 的计算公式，变得更简单一点

WeightNorm

和 RMSNorm 的工作其实非常像，而且更简单 \[WeightNorm(x) = \frac{x}{||x||_2}\gamma\] \[||x||_2 = \sqrt{\sum_{i=1}^{N} x_i^2 + \epsilon}\]

对比一下可以发现，WeightNorm 和 RMSNorm 就差了一个 \(\sqrt{N}\)，但是从上图的效果对比来看，也就是 L2-Norm 那根线，效果和 RMSNorm 还是差不少的。这大概率是因为变长序列带来的影响，WeightNorm 并没有考虑长度的问题。所以去掉 \(\sqrt{N}\) 这条路已经走不通了。

那改变其他的归一化方式呢？比如计算更简单的 L1 norm? 并不是那么好，因为 L1 norm 在 0 点不可导，虽然可以通过一些 trick 避免，但是总归是不太优雅
