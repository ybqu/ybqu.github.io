激活函数在神经网络中的作用

激活函数在神经网络中的作用

1. 代数角度：引入非线性（Introduce Non-Linearity）

这是最根本的目的。如果没有激活函数，无论神经网络有多少层，其最终的输出都只是输入数据的线性组合（想象一下矩阵连乘，最终还是一个矩阵）。线性模型的能力极其有限，根本无法拟合现实中复杂非线性的 patterns（比如简单的xor（异或）、图像、视频、语音、语言等数据特征）。激活函数通过一个非线性的映射，使得神经网络成为了一个“万能函数逼近器”，能够拟合极其复杂的函数（这个理论称作Universal Approximation Theorem）。

2. 信息学角度：决定神经元的激活状态（Determine the Firing of a Neuron）：

从信息论的角度来说，神经网络就是对信息的增强和压缩。这里激活函数就起到了很重要的作用。
激活函数除了做非线性映射，还在某种程度上对前一层的信息进行了筛选和加强，尤其是近期越来越流行的门控激活函数更加验证了这一点。 激活函数的存在，让模型能够丢弃噪音，保留相关信息，提高模型的决策能力和泛化能力。

激活函数的输出定义了当前神经元是否被“激活”，以及被“激活”的程度。它像一个水闸，控制着信息流向下一层的流量和形式

3. 微积分角度

既然激活函数必不可少，那什么样的不同的激活函数对神经网络有什么影响呢？ 反向传播就可以检验激活函数的好坏，精心设计的激活函数可以保证模型在训练的时候有一个稳定的梯度流。

常见的激活函数

Sigmoid

1. Sigmoid

sigmoid 和 softmax 属于从统计机器学习中引申过来的非线性函数。在广义线性模型中，sigmoid 可以认为是伯努利分布链接函数的逆，而 softmax 可以认为是多项式分布连接函数的逆。

sigmoid 作为中间层的激活函数并不多(如LeNet)，更多的是出现在神经网络最后一层，延续其在广义线性模型中的作用，用来拟合概率分布

Sigmoid的问题

a. 梯度消失

sigmoid 函数: \[\sigma(z) = \frac{1}{1 + e^{-z}}\] 求导： \[\sigma^{'}(z) = \sigma(z)\cdot(1 - \sigma(z)) = \frac{e^{-z}}{(1+e^{-z})^2}\]

从图中看出，导数的有效区间大概也就在 [-6, 6]

所以，sigmoid 的值一旦进入饱和区，梯度就趋近于0，也就是面临梯度消失的问题

Word2vec的实现中，在计算 sigmoid 的时候采用了查表法来计算，把 [-6, 6] 之间进行了切片然后存储其数值，对于小于 -6 的就直接设置为0， 大于 6 的直接设置为1. 也就是说 sigmoid 本身的有效区间大概为 [-6, 6]

b. 收敛太慢

假设通过某种手段(比如缩放等)，完美的将输入控制在 [-6, 6] 之间，那是否可以使用呢？（❌）

假设一个神经网络的隐层都采用了 sigmoid 作为激活函数。我们取某一个节点，将其表示为 \[z = x_1\times w_1 + x_2\times w_2 + ... + x_n\times w_n\] \[y = \sigma(z)\]

\(x_i\)表示前一层的输入，如果不是第一层，则\(x_i>0\)；假设没有0即没有梯度消失

求导： \[ \frac{\partial y}{\partial w_i} = \frac{\partial y}{\partial z}\frac{\partial z}{\partial w_i} \\ =\sigma(z)\cdot (1-\sigma(z))\cdot x_i \]

通过公式可以发现，式子中的三个数全为正，也就是梯度永远是正数。

最终这个神经网络除了第一层的输入 \(x\) 可能为负那么其梯度为负数，其他层的梯度都是正数。这就导致模型收敛变得十分困难。

Tanh

sigmoid 的性质导致其导数全为正数，导致这样的其中一个原因（并不是全部的原因）是：sigmoid 的值的范围在 0-1 之间

如果将 sigmoid 函数变成 zero centered，那么其值就有正有负，sigmoid 收敛慢，不稳定的原因就解决了。

那么 sigmoid 如何 变成 zero centered 呢？

sigmoid 的范围在[0, 1] 之间， 其实只需要减去 0.5 就可以了

定义函数：\(g(x) = \sigma(x) - 0.5\)
推导： \[ \begin{aligned} g(x) & =\sigma(x)-0.5 \\ & =\frac{e^{x}}{1+e^{x}}-\frac{1}{2} \\ & =\frac{2 e^{x}-1-e^{x}}{2\left(1+e^{x}\right)} \\ & =\frac{e^{x}-1}{2\left(1+e^{x}\right)} \\ & =\frac{e^{-\frac{1}{2} x}\left(e^{x}-1\right)}{2 e^{-\frac{1}{2} x}\left(1+e^{x}\right)} \\ & =\frac{e^{\frac{1}{2} x}-e^{-\frac{1}{2} x}}{2\left(e^{\frac{1}{2} x}+e^{-\frac{1}{2} x}\right)} \\ & =\frac{1}{2} \tanh \left(\frac{1}{2} x\right) \end{aligned} \]

则得到： \[tanh(x) = 2\sigma(2x) - 1\]

tanh 作为激活函数，本质上就是对 sigmoid 做了个 zero centered 操作

  • 先把 sigmoid 在x轴挤了一下，然后在 y 轴上拉伸，最后减去中心点，相当于平移成一个 zero centered 的函数。

这样解决了梯度全为正（或者全为负）的问题

但是依然没有解决梯度消失的问题。从上图可以看出，tanh 的饱和区大概在 [-3,3] 之间。即使这样，tanh 在实际的使用效果上，已经比 sigmoid 要好很多了

ReLU

RELU只是把负数变成0，为什么可以作为激活函数？激活函数的本质是什么？

2012年， AlexNet 在 ImageNet 竞赛中一举夺魁，引爆了深度学习。在论文中，采用了 ReLU 作为激活函数，并且证明了其有效性。

ImageNet Classification with Deep Convolutional Neural Networks

从 AlexNet 之后， ReLU 就迅速替代了 sigmoid/tanh，成为深度学习最常用的激活函数。

然而ReLU 早在 1941 年就被 Alston S. Householder 在论文 A theory of steady-state activity in nerve-fiber networks: I. Definitions and preliminary lemmas 中提出。

其思想来源于人类的神经元。人类的神经元会接受其他神经元输入的电信号，但是只有输入的电信号超过一定的阈值才会输出信号给其他的神经元。

ReLU 的优点

ReLU 之所以能流行，原因总结如下：
1. 计算足够简单
2. 缓解了梯度消失的问题

ReLU、sigmoid 和 tanh 的导数如下：

可以看出，sigmoid 和 tanh 在 x 很大或者很小的时候，梯度迅速降为0，参数就基本没有更新了

而 ReLU 在输入 x 为正数的时候梯度为 1，此时没有梯度消失的问题。然而当值为负数的时候，梯度为0，此时依然有梯度消失的问题

所以 ReLU 并没有完全解决梯度消失的问题。一个不太准确的说法，可以说是解决了“一半”的梯度消失问题(x > 0)，对于另一半(x <= 0)则直接弃疗了

3. 把非正数部分设置为0，起到了一定的稀疏化的作用。

这样的机制使得模型可以减少参数量，从而在参数量很大的时候起到了一定程度的正则化作用。跟 L1 正则有点类似，但是 L1 正则是直接将某些参数丢弃，而 ReLU 则是动态的调整参数是否激活

4. 训练更稳定，更容易收敛

计算简单，再加上梯度消失有所缓解，使得带有 ReLU 的神经元相比于 sigmoid 或者 tanh 训练更加稳定和容易收敛。

ReLU 的缺点

1. 一些使用 ReLU 的神经元会变成死亡神经元

也就是说对于任何输入其输出都是0。少量的死亡神经元也许会提高模型的泛化能力，但是当神经网络中大量神经元都死亡时，模型的拟合能力会极大的削弱。

2. 输出的范围[0, inf], 可能导致神经网络崩溃
3. 在 0 处不可微，需要加 if else 处理
4. not zero-centered 可能会导致反向传播时存在 zig-zagging 的问题

ReLU的改进

针对 ReLU 的缺点，目前大致有如下方法来优化

随机初始化方法和超参数优化

ReLU 的输入，一般都是 \(Wx + b\) 这样的 linear，所以：

  • 当 bias 的值为一个绝对值很大的负数的时候，神经元就容易死亡
  • 同理，\(W\) 和 \(b\) 都是通过梯度下降来更新的，以 \(W\) 为例，\(W = W + lr\times G\)，其中 \(G\) 为梯度，lr太大也不行

所以很多参数初始化方法都是围绕如何让参数的绝对值不要太大展开的，例如：《Dying ReLU and Initialization: Theory and Numerical Examples》

早期也有通过正则化来防止参数过大过小的方法，但是现在用的不多了。

Normalization

另一个常用的方法就是 Normalization，常用的有 LayerNorm， BatchNorm 等

改进或者替换 ReLU

以下的方法都是对 ReLU 进行了一些改进，其形状跟 ReLU 很像但是又各自不同。

  • Leaky ReLU

导致神经元死亡的根本原因是 ReLU 碰到负数会变成 0 值，那让 ReLU 碰到负数不再输出 0 就好了。这就是 Leaky ReLU 的思路，其公式为： \[ LeakyReLU(x) = \begin{cases}x & \mathrm{if}\quad x\ge 0\\ \alpha x &\mathrm{otehwise} \end{cases} \]

  • Exponential Linear Unit (ELU)

ELU 借用了 Leaky ReLU 的思想，该函数将负数部分变成了 \(\alpha(e^x - 1)\) ，同样可以解决负数梯度为0 的问题 \[ LeakyReLU(x) = \begin{cases}x & \mathrm{if}\quad x\ge 0\\ \alpha (e^x - 1) &\mathrm{otehwise} \end{cases} \]

  • GeLU

\[GELU(x) = x * \Phi(x)\]

GeLU 开创了一个新的赛道。GeLU 采用了用 \(x\) 乘以一个S形曲线来达到模拟 ReLU

其实只要找到一个输入域为 [-inf, inf], 输出域为 [0, 1] 之间的函数，然后再乘以\(x\)，其形状就和 ReLU 类似。

常见的 S 形曲线：\(sigmoid, tanh, erf(x), (1 + e^{-x})-\alpha, \frac{x}{\sqrt{1+x^2}}\)， 等等，都可以通过平移和缩放来使其输出在 0 到 1 之间。

GeLU 选择使用 \(erf(x)\) -即正态分布的积分函数 \[\Phi(x) = \frac{1}{2}\left(1+erf(\frac{x}{\sqrt{2}})\right)\]

但是这个函数算起来挺麻烦，所以经常会用其他函数来近似，比如 \(x * \mathrm{sigmoid}(1.702x)\) 或者 \(0.5x\left(1+\mathrm{tanh}[\sqrt{2/\pi}(x+0.044715x^3)]\right)\)

  • SiLU

GELU 的论文里同步也提到了 SiLU，就是把 GeLU 的近似 \(x * sigmoid(1.702x)\) 中的常数项去掉，变成了 \(x * sigmoid(x)\)

  • Swish

Swish 和 SiLU 的唯一区别就是在 sigmoid 中加入了一个可训练的参数\(\beta\) \[Swish(x) = x * sigmoid(\beta x) = \frac{x}{1+e^{-\beta x}}\]

  • GLU

GLU 严格意义上不能算是一个激活函数，其实是一层神经网络。 \[GLU(x,W,V,b,c) = sigmoid(xW+b)\otimes(xV+c)\]

可以将其看作是一个超级简化版本的 LSTM 或者 GRU。只有一个门来控制输出。

  • GEGLU/SwiGLU

GLU 做的改进是将 SiLU 中的 x 变成了 linear(x), 而SwiGLU把 sigmoid 换成前面提到的其他 S 型曲线，就变成了新的 xGLU，比如： \[GEGLU(xW,,V,b,c) = GELU(xW+v)\otimes (xV+c)\] \[SwiLU(xW,,V,b,c\beta) = Swish_{\beta}(xW+v)\otimes (xV+c)\]

这项工作的作者是 Transformer 发明者之一，同时也是 Character.ai 的创始人。

作者表示他也不知道SwiGLU效果为什么这么好，把原因归结为“上帝的仁慈”。

  • Maxout

Maxout 不再是从 0 和 输入\(x\)中选择最大值，而是从多个神经元中选择一个最大值。 ReLU 可以认为是 Maxout 的一个特例和变体。

Maxout 几乎没有梯度消失的问题，除非输入全是0。但缺点是参数量大，计算复杂度较高，而且最终效果上和其他常用激活函数没有显著拉开差距，所以并没有特别流行。

ReLU 依然很能打

SwiGLU 和 GEGLU 在很多 LLM 上都使用了，可以说基本上成为 LLM 的标准用法。但是苹果的一项研究表明，ReLU 之后的这些花里胡哨的研究在 Scaling Law 面前都是花拳绣腿，只要算力和数据够大，这些改进比起使用 ReLU 的提升极其有限。

而且这么做失去了 ReLU 的稀疏性，不利于推理的优化。在利用 ReLU 的稀疏性对推理进行优化后，推理的计算量可以降低 3 倍。

扩展问题

  1. 常见的激活函数有哪些？它们各有什么特点和适用场景？
  2. ReLU（Rectified Linear Unit）激活函数为什么在近年来变得如此流行？它解决了什么问题？
  3. 激活函数对梯度流动有什么影响？例如，如何解释ReLU在解决梯度消失问题上的作用？
  4. Softmax函数通常用在神经网络的输出层，它的作用是什么？
  5. Swish、GELU等较新的激活函数带来了哪些改进？它们在哪些场景下表现优秀？
  6. 既然 sigmoid 不是 zero-centered 导致了很多问题，如何改进？
  7. 在某些特定场景下（如二分类问题的输出层），Sigmoid 仍然会被使用。在这些情况下 Sigmoid 是否合适？
  8. 是否了解 sigmoid 的一些变体，比如 Hard Sigmoid？

权重共享 权重共享（Weight Sharing）就是在模型的不同部分使用相同参数的技术。有时候也叫 Parameter sharing, 或者 Weight Tying 权重共享的优缺点 参考Weight Tying部分 优点： 可学习的参数变少，模型更容易训练，收敛更快 在内存受限、需要通信的推理场景，能够加快推理速度 权重共享有一定的正则化的作用，因为可学习的参数变少了 -> 相当于提升了模型的泛化能力。这个理论可以从 Bias Variance Trade-off 的角度来证明（码农要术：机器学习篇：泛化挑战） 缺点： 一些权重可能理论上在完成任务的功能上就是正交的，共享之后可能会有新的问题。比如 词向量与 LM Head 的共享可能导致各向异性的问题 神经网络中常见的一些权重共享 基于位置的共享 CNN 中，同一个卷积核的权重在整个图像的不同位置是共享的。而 Transformers 中的 FNN 层也类似，序列的不同位置共享 MLP。 嵌入层和输出层权重共享 即常说的 Weight Tying, 将词向量与最后的 lm head 的权重进行共享。...
