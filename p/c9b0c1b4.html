PositionEmbedding的作用

发表于2025-08-31|更新于2025-08-31|LLMsTransformersEmbedding
|总字数:725|阅读时长:2分钟|浏览量:

首先要知道 transformers 是设计用来做机器翻译的，当机器翻译的架构从 RNN 进化到 transformers 之后，位置信息就丢失了

和 RNN 的逐步迭代相比，attention 可以认为是个全连接图（如果是 causal attention 则有些边断开），不会考虑位置
这样就导致对于 attention 看来，“八王大“和“大王八” 是一样的

所以 Position Embedding 的作用，就是在把 Word Embedding 送入 attention 之前，把位置信息给带上。

论文中的给出了一个绝对位置编码，叫 Sinusoidal Position Embedding，这个编码会和输入的词向量相加。文中的位置编码函数如下： \[PE(pos, 2i) = sin(\frac{pos}{10000^{2i / d_{model}}})\] \[PE(pos, 2i+1) = cos(\frac{pos}{10000^{2i / d_{model}}})\]

We chose this function because we hypothesized it would allow the model to easily learn to attend by relative positions, since for any fixed offset \(k\), \(PE_{(pos+k)}\) can be represented as a linear function of \(PE_{pos}\).

简单来说，就是该函数是相对位置k的一个线性变换，也就是符合这么一个特性： \[PE_{pos+k} = f(PE_{pos},k)\] 这个特性就让模型能够捕获相对位置关系

Sinusoidal Position Embedding 的物理含义

直观的理解

Transformers处理的是一个序列，Position Embedding 表示的是输入的位置。在序列模型里，输入的位置也可以认为是时间，比如第i个位置的输入与第i时刻输入是一样的，只是表达方式的不同

我们可以想一下时间是怎么表示的？

虽然也有时间戳的表示方法，但是最常用的肯定还是用小时 分钟 秒来表示。 那么 03:14:15 时刻过了 3小时3分钟3秒，变成了 06:17:18

此时 时针转了360 * 3/12度，分针转了 360 * 3/60 度，秒针转了 360 * 3 / 60 度

如果我们把时针、分针、秒针用向量来表示，那么在经过相对时间 k 之后，这三个向量分别进行了旋转 如果位置编码只有6维，也可以表示成3个向量，那么在间隔了相对位置 k 之后，这三个向量也分别进行了旋转。而且故意设计成每个向量的旋转角度都是 k 的倍数。如下图：

扩展问题

直接用0，1，2，3… 来表示位置编码行不行？

  • 泛化不好，没见过的位置模型处理不好
  • 模型的权重会存在很大的数字，神经网络不喜欢大数字，影响训练的稳定性
  • 那如果是将位置做个归一化呢？也很难，因为无法找到一个归一化的标准
